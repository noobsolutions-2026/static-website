Tool Use / Function Calling

The mechanism by which an LLM emits a structured request to call an external function — and receives the result back as context, extending its capabilities beyond text generation.

Model Context Protocol (MCP)

An open standard for connecting LLMs to external tools, data sources, and services — so any model can use any tool without custom integration code.
